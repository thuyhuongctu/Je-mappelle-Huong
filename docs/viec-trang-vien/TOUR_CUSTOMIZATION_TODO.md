# Tour customization

- [x] Kiểm tra biến tốc độ auto-tour và danh sách điểm khu hiện có.
- [x] Thêm lựa chọn tốc độ chậm/vừa/nhanh với nhãn và phản hồi rõ ràng.
- [x] Cho phép đánh dấu/bỏ đánh dấu điểm dừng yêu thích.
- [x] Cho phép tour chỉ chạy qua các điểm yêu thích khi có lựa chọn.
- [x] Lưu tốc độ, favorites và chế độ tour bằng localStorage.
- [x] Kiểm thử trên desktop và mobile, không chồng với joystick/HUD.
